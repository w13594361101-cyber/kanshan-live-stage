# 看山有问｜现场互动台

为浦江创新论坛设计的刘看山现场互动工具。看山从五道预审问题中随机抽题，再依次抽取一位分享嘉宾和一位点评专家。

## 页面入口

- `/`：公开产品首页
- `/?view=stage`：现场大屏，隐藏所有控制按钮
- `/?view=stage&demo=1`：带演示控制的大屏
- `/?view=control`：工作人员控制台

## 本地运行

```bash
pnpm install
pnpm dev
```

正式构建：

```bash
pnpm test
pnpm build
```

## 部署兼容性

构建产物位于 `dist/`，全部使用相对资源路径，不依赖服务端接口、数据库或 GitHub 专属能力。可部署到：

- GitHub Pages
- 知乎静态网页托管环境
- 任意静态服务器或对象存储
- 现场电脑本地静态服务

运行时配置保存在当前浏览器的 `localStorage`。控制台和舞台页在同一浏览器中通过 `BroadcastChannel` 同步，并以 `storage` 事件作为兼容回退。

## 内容配置

默认五道问题、五位分享嘉宾和五位点评专家均为占位内容。可直接在控制台编辑并保存；仓库默认值位于 `public/config/activity.json`。

## 现场建议

1. 使用同一台电脑打开控制台和舞台页。
2. 将舞台页全屏输出至 LED 大屏。
3. 活动前关闭系统通知并完整走完五轮彩排。
4. 下载一份 `dist/` 作为离线备份。
